Entrants write one resignation letter, exactly one line long (1 to 140 characters), whose only job is to be funny. A judge model compares entries two at a time and picks the funnier one-line resignation letter.

> Dear Manager, I resign effective immediately; my two weeks' notice is the vacation you denied twice, so consider this me finally taking it.

## Run it

```sh
python3 main.py
```

Writes the line to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`). Standard library only, deterministic, no network.
